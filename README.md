# capture 入仓回收与重开续办

Python 3.11 + 标准库 `sqlite3`，无第三方依赖。源事件库 `S` 与入仓库 `C`
使用**两个独立 SQLite 文件分库**；传 `None` 路径为内存库（仅建库态可用，
内存库不支持 `None` 重开）。

## 运行

```bash
python3 -B -m unittest discover -s tests -v   # 21 项契约回归
python3 -B verify_crash.py                    # 子进程硬退出(os._exit)后的中断核验与续办
python3 -B demo.py                            # 题给叙事的完整演示
```

`.pointwise-runtime.json`：`verify` 指向 `verify_crash.py`（非零退出即失败），
`demo` 指向 `demo.py`。

## 接口契约

### 源事件库 `S(db, seed)` / `S(db, None)`

| 成员 | 语义 |
| --- | --- |
| 构造 | 带 `seed`（事件列表）建库并绑定源 id（关键字 `sid`，默认 `"source"`）；`None` 重开已存在的库；重复 seed / 重开未初始化库 / 重开源 id 不符 → `CaptureError` |
| `next(i)` | 返回位置 `i` **之后**第一条 `(pos, ev)`；尽头 `None`；`i < acked` 拒读；`i=None` 视为 0 |
| `ack(i)` | 单事务原子删除 `1..i` 并推进 `acked`；幂等（重复/回退位置返回 0），返回新删除条数 |
| `acked` / `sid` | 已确认位 / 绑定的源 id（持久） |
| `close()` | 关闭连接，幂等 |

### 入仓库 `C(db, seed)` / `C(db, None)`

`seed = {键: {"x": int, "y": int, "note": str | null}}`。

| 成员 | 语义 |
| --- | --- |
| `pump(s, n, h=None)` | 绑源 id 后从 `s` 拉取，至多 `n` 条；`n=None` 不限，`n=0` 不接纳新事件但**仍先补确认**；返回新收条数 |
| `read()` | `[消费位, 确认请求位, 仓行(按键排的[键,整行]), 回执表]` |
| `preview(t)` | 以合法且未使用的标签 `t` 假设此刻提交，返回与提交同逻辑的快照；只校验不消费 `t`，不产生回执 |
| `close()` | 关闭连接，幂等 |

## 事件（位置从 1 编号）

| 事件 | 含义 |
| --- | --- |
| `[b, t]` | 在根下开父域，路径 `/<t>` |
| `[s, t, u, p]` | 在活父域 `p` 下开子域 `u`，路径 `p + "/" + u` |
| `[w, t, u, k, 补丁]` | 在活域 `u` 对键 `k` 写补丁，列限 `x:int / y:int / note:str|null`，`null` 可写 |
| `[r, t, u]` | 撤回活域 `u` 子树（根域 `""` 不可撤）；子树内补丁同时失效 |
| `[c, t]` | 提交，冻结回执 `[t, 提交位置, 按键排的[键,整行]]`；**空提交也发** |
| `[a]` | 确认请求；确认不提交，本地事务持久后才 ack 源 |

通用不变量：

- 空串 `""` 为根域；所有引用必须指向**活域**，否则 `CaptureError` 且位置不推进。
- 父号（根下一级）与父内子号全局不复用，撤回后也不可再建；标签 `t` 同样不复用。
- 整行 = seed 初值（新键默认 `[0,0,null]`）叠加**幸存补丁**，按事件位置序覆盖；
  回执在提交时刻冻结，后续写入与撤回不改写旧回执。
- 非法事件（结构、类型、引用、复用）或带未确认事件换源 → `CaptureError`，
  校验先于事务，任何已持久位置均不回退/不前进。

## 钩子 `h(phase, i, ev)`

- `h(0, i, ev)`：接纳 `[c,t]` 提交**之前**；
- `h(1, i, ev)`：提交事务持久**之后**；
- `h(2, i, ev)`：源确认完成**之后**（含重开补确认，此时 `ev=None`）。
钩子内异常原样透传；提交钩子失败时该事件事务回滚、位置不推进。

## 崩溃恢复与换源

- 每条事件一个 `BEGIN IMMEDIATE` 事务：域/补丁/标签/消费位同事务落盘；
  `[a]` 在事务提交成功后才调用源 `ack`，并把确认位持久到入仓库。
- 重开时 `pump` 先做补确认（对同一源幂等重放 `last_ack`），`n=0` 也执行；
  源事件仅在本地可恢复后才被删除。
- 换源：仅当旧源 `consumed == last_ack`（全部确认）时允许绑定新源 id，
  新源位置从 1 重新编号，内部全局位置 (`pos_base`) 接续避免主键冲突；
  旧仓行与历史回执保留。
